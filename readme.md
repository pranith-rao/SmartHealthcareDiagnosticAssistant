**Smart Healthcare Diagnostic Assistant** is a powerful MERN stack application designed to support healthcare providers with AI-driven clinical decision-making. It combines evidence-based clinical rule engines, medical imaging analysis, and comprehensive treatment planning to bridge the gap in specialist availability. By integrating patient vitals, symptoms, and diagnostic history, it provides a holistic view of patient health, making diagnostic support more accessible and efficient.

## Getting Started
- **Method 1 (Recommended)**: Double-click `Team_CursorMinds_Submission.bat` to automatically install dependencies, build the frontend, and start the application.
- **Method 2 (Docker)**: If you have Docker Desktop running, double-click `Team_CursorMinds_Submission_Docker.bat` to build and start the application in a containerized environment.
- Once the application starts, it will automatically open your browser to `http://localhost:3000`.
- **Note**: No external MongoDB installation is required as the system uses an optimized in-memory database for evaluation.

## Key Features:
- **Diagnostic Engine**: Rule-based analysis using CHADS2, qSOFA, and ACS risk assessment models.
- **Medical Imaging**: Drag-and-drop support for analyzing X-rays and medical scans.
- **Treatment Planning**: Automated generation of evidence-based management protocols and medication plans.
- **HIPAA-Compliant**: Secure data handling with JWT authentication and comprehensive audit logging.
- **Animated UI**: Responsive and fluid dashboard built with React and Framer Motion.

## Screens & Functionality
- **Dashboard**: A central hub providing a high-level overview of clinical operations with beautiful animated stat cards.
- **Patient Management**: Securely register and track patient profiles, medical history, and vital signs in a unified interface.
- **Diagnosis Center**: Input clinical findings to generate differential diagnoses, clinical reasoning, and evidence-based "pearls."
- **Imaging Lab**: Dedicated section for uploading and reviewing medical imaging studies with integrated analysis tools.
- **Clinical Reports**: Generate and export professional medical reports in PDF format for documentation and sharing.

## Info
